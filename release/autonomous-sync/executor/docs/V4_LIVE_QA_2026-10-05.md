## Co naprawiono i dlaczego

1. Hero: usunięto dekoracyjny samochód i zarezerwowane miejsce; rzeczywisty formularz wyśrodkowany. Zachowano granat/czerwień, widoczną markę **REXBID** bez kropki. Nazwy infrastruktury i storage keys pozostają techniczne.
2. Jedno źródło kategorii `rexbid-market.js`: Aktualne, Timed, Kup teraz, Elektryczne. Predykaty SQL działają przed paginacją, a frontend używa zgodnej semantyki. Archiwalne oferty i wygasłe Buy Now nie są udawanymi aktualnymi ofertami; EV wynika z jawnego napędu.
3. Adapter pomijał `vehicle_specs` oraz fizyczne `facility.canonical`. Napęd, nadwozie, skrzynia, stan/ZIP i rzeczywista lokalizacja są teraz mapowane; wirtualna nazwa aukcji nie zastępuje placu transportowego. Odometer zachowuje kontrakt `{value, unit}`. Obiekty trim nie stają się `[object Object]`.
4. Dokładny VIN/LOT usuwa wcześniejsze filtry. Linki katalogu i ulubionych zachowują VIN + LOT + platformę. Karta nie wybiera pierwszego przypadkowego rekordu ani innego relistingu.
5. Matcher transportu rozpoznaje dokładną nazwę placu z podanym ZIP (np. `Los Angeles` + `90248` wobec wiersza `Los Angeles 90248`). Nie jest to fuzzy match. Niejednoznaczny ZIP można rozstrzygnąć tylko posiadanym, dokładnym city/state; inaczej ambiguous.
6. V4 ma jeden kompaktowy wynik: zakup, aukcja, łączny transport, podatki, obsługa/dostawa; pełne rozbicie w szczegółach. Unknown nie jest zerem. BEV +150 USD raz; HEV/PHEV wymagają potwierdzenia, ICE pokazuje „Nie dotyczy”.
7. HTML wersjonuje zmienione JS/CSS hashem, aby cache przeglądarki nie pokazywał starego kalkulatora po deployu. Gate produkcyjny rozpoznaje także wersjonowany URL V4 i nadal usuwa V4 poza zatwierdzonym stagingiem.
8. Home i karta formatują potwierdzony timestamp w `Europe/Warsaw`, z poprawnym przejściem przez północ. Data bez godziny pozostaje bez zgadywania godziny; unassigned nie dostaje countdownu.
9. Film IAAI `EngineVideoRetriever` zwraca HTTP 200 `video/mp4`, mimo braku rozszerzenia. Wcześniej traktowano go jak iframe, blokowany przez CSP. Teraz jest natywnym video; potwierdzono odtwarzanie 1280 px / readyState=4 / postęp czasu. Bez rozluźniania CSP.
