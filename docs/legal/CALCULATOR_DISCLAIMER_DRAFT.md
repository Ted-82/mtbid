# Informacja o kalkulatorze kosztów

**DRAFT — REQUIRES OWNER/LEGAL REVIEW**

Calculator V3 prezentuje szacunki informacyjne, nie ofertę ani gwarantowany koszt dostarczenia. Stawki transportowe partnera są konfiguracją roboczą w USD; wynik zależy od dopasowania lokalizacji i dostępności kompletnej trasy. Opłaty aukcyjne mogą wymagać wyboru/ potwierdzenia profilu. Podstawy celne, klasyfikacja, kursy, VAT/akcyza, port, broker, obsługa importowa i transport w Polsce pozostają częściowo nieznane lub konfigurowalne. Brak danych nie oznacza kosztu zero; niepełny wynik nie powinien być interpretowany jako pełna kwota pod dom. Potwierdzenie kosztu wymaga aktualnej wyceny partnera i właściwego specjalisty.
